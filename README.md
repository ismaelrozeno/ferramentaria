# Sistema de Ferramentaria

Sistema para gestão de ferramentaria.

## Fluxo de desenvolvimento

1. Design no Figma
2. Validação com o cliente
3. Desenvolvimento por funcionalidade (fatia vertical):
   - rota no back-end
   - teste unitário
   - tela no front-end
   - teste de integração front ↔ back
   - só então a próxima funcionalidade
